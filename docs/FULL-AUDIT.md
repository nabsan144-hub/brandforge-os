# Independent full-package audit — 1.4.1

## Scope and honesty

The input was the exact 1.4.0 Source ZIP at commit `53d4d0d373528f06bbae180d348de81565d8d4dc` (SHA-256 `40e9e641cedc3ce87382732d343adc3f56f0ad9ddf74580f98c881cac8a88736`). All 415 original payload files were inventoried and byte-verified. The review used source inspection, syntax/format analysis, dependency checks, actual SQL/handler tests, clean packaging and browser/asset checks—not just the earlier changed-file list.

This is a bounded engineering audit, not a proof that every possible input or executable line is correct. The evidence distinguishes tests, fixtures, generated/vendor/binary checks and retired code; statement coverage is reported separately. Fonts/media are decoded and integrity-checked rather than described as line-by-line executable code. The historical duplicate hosted subsystem is retired, not certified as production-ready. There is no Next.js application in this project: its supported stack is Python/FastAPI + Svelte/Vite Desktop, JavaScript/Vercel + Supabase Cloud, and static marketing.

No live deployment, real purchase/refund, provider-quality, inbox, native Windows/macOS/Word or legal sign-off was fabricated. Those owner actions are in OWNER-GUIDE.md and LAUNCH-RUNBOOK.md. The public brand/support email were retained as requested; a legal entity/jurisdiction was not invented. Checkout remains off in the supplied source.

## Decisions and residual validation

- Kept prices and navy/gold/paper identity. Desktop ownership and recurring Cloud subscriptions remain separate.
- Removed the redundant Cloud prototype rather than exposing its incompatible billing/security behavior. Git history retains the original.
- Preserved required license notices and actual sample disclosures; moved operator-only information out of public/customer surfaces.
- Website pages use clean routes. Real downloadable HTML/PDF/MP4 files and the Google verification file keep their required extensions.
- Public-site audits use a restricted browser/fetch path, not an OS-level malware sandbox. Use supported, patched browsers and do not publicly expose Desktop.
- Desktop mutation locks coordinate managers within one process, not arbitrary independent processes or manual file editors. Run one writer instance per data folder and retain backups.
- The first measured Desktop production-code pass had 72.3% statement coverage, not 100%. Final counts/coverage and exact artifact hashes accompany the handoff; passing tests do not prove profitability, legal compliance, search ranking or perfect customer satisfaction.
- Some inherited tests encoded unsafe behavior (raw error reflection, unchecked image magic, silent BYOK fallback, immediate repeated delivery). Their assertions were strengthened, not suppressed. A missing Brotli decoder in the audit environment was corrected; it was not a font-file defect.
