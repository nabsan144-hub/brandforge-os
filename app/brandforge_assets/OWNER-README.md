# BrandForge OS Desktop

This is the complete local Desktop runtime. Your purchase receipt and `LICENSE` define your usage rights. It does not include a Cloud subscription or development-source resale rights.

1. Extract the whole archive into a writable folder.
2. Follow `START-HERE.md`. On Windows, run `SETUP-WINDOWS.bat` once while online, then `START-HERE.bat` for ordinary launches.
3. Start with Offline text/templates. Configure a supported provider only if you want connected features and accept that provider's processing and fees.
4. Review the generated copy and visual assets before publishing. Saved text revisions do not automatically redesign images.
5. Keep a backup of your data folder. Portable installs store data beside the app unless `BRANDFORGE_DATA_DIR` is configured; installed Python wheels use a per-user data folder.

See `docs/DESKTOP-USER-GUIDE.md` and `docs/NETWORK-PRIVACY.md` for details. The local server accepts loopback connections, not public hosting. For browser-hosted use, choose the separate Cloud product.
