Frequently asked

How do I receive the software after purchase?

At paid launch, our verified order service sends a signed, tier-specific download link after Paddle confirms payment. No Cloud login is required. Unzip the complete folder and follow START-HERE.md. Initial setup downloads dependencies; later offline launches do not run pip. Installation time varies.

Does it work fully offline?

Desktop templates work offline after setup. The dashboard tracks requests-library traffic only, not every transport or process. Connected providers receive prompts and selected brand context; optional image/search/update features can also use the network. Cloud stores your workspace remotely. See Privacy for the deployment differences.

Is the offline output good enough to use as-is?

Offline mode is private, draft-quality templates — a fast, honest starting point, and every campaign ships with a quality score and claim-guard warnings so you can review before publishing. For provider-generated drafts, connect a supported provider in Settings. Provider pricing and limits apply, and generated claims still need review. We say this plainly because we'd rather earn trust than fake a demo.

What happens if BrandForge disappears one day?

Your software keeps working — that's the structural difference from a subscription tool. There is no license server to phone home to: the local runtime does not require online activation; your purchase receipt and license define your rights. No accounts, no activation checks, no kill switch. If we vanished tomorrow, you could keep using the version you received on a compatible system; future OS and provider compatibility are not guaranteed (the optional update check pings GitHub releases only, and can be switched off).

What's the difference between Owner and Agency + Source?

Both are one-time, owned-forever desktop licenses for the same full product — they differ by license scope. Owner ($199 once) is internal business use: one user, your own brands, the full 6-stage pipeline and all 21 tools. Agency + Source ($499 once) adds commercial rights — unlimited client brands, white-label deliverables and the resell right — plus the full build source (dashboard source + CI) and an onboarding session if you brand and sell it yourself.

Does it generate real AI images?

Yes. On desktop, AI Image Design generates real brand photography through your own API key — Gemini, Grok Imagine or OpenAI gpt-image-1 — and composes your brand colors, headline, benefits and CTA on top, exported as PNG and JPEG (set it up in Settings → AI Image Design). Without a configured image key, template visuals remain available. A public image service is an advanced opt-in; it is not used automatically. Offline text/templates require no network, but explicitly connected features can still send requests. The browser Cloud plan currently ships an SVG hero and does not advertise image quotas.

Do I need to be technical or know coding?

Honest answer: the desktop runs on your own computer, so you need Python 3.10+ (free, usually a short install). One requirements file and a 30-second onboarding wizard do the rest — on Windows it's a double-click (START-HERE.bat), on Mac/Linux it's three commands, and no coding is required after that. Not your thing? Agency + Source includes one scheduled onboarding session on a screen share (~20 minutes), subject to availability. Owner includes documentation and email support. Or skip install entirely: Cloud Free/Pro/Agency runs in your browser with zero setup.

Are Owner and Agency + Source different downloads?

Both desktop tiers ship the same full application — the difference is license rights (personal vs client work and resell), stated in the EULA. Agency + Source additionally ships the full build source. Cloud Free/Pro/Agency are separate hosted plans with server-enforced limits.

What if it's not for me?

14-day money-back guarantee — email support with your order ID and we will process an eligible request. You keep the delivered version. Maintenance and security updates released in the first 24 months are included; perpetual support or future features are not promised.
