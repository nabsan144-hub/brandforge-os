# Product tour assets

60-second illustrated walkthrough. Northline Coffee is fictional. The campaign art/PDF is offline-generated; Desktop screenshots are actual local interface captures; Cloud screenshots use example auth/account/API data. The brief card is a styled overview. This is not a real-time generation benchmark, live provider session, purchase, refund or delivery verification.

`demo.mp4` is a web-optimized H.264/AAC encode of the supplied 1080p/30fps master, with the same scenes and original instrumental soundtrack. `tour.html` is the self-contained animated alternative with embedded images, music, fonts and font notices. Production links outside its player point to this website's pricing and sample pages. No voiceover or live checkout is embedded.

The tour demonstrates the local 1.4 interface before final label-only polish. Its editing/export workflow is unchanged. See docs/PRODUCT-DEMO.md for integration and checks.
