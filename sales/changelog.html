1.9.0 — bold creative engine (in development, not yet released)

Vivid, business-specific ad compositions for every generated banner on Cloud and Desktop: organic corner blobs in your brand colours, a rotated paint-band carrying the oversized brief headline, star-spark stickers, a pictogram benefit strip and an optional offer punch line. Every output is derived from your own brief (colours, words, benefits, offer, logo), so two businesses never receive the same creative. Text stays exact outlined vector copy in English, Urdu/Arabic (RTL-mirrored layout) and Hindi. A style: essential option keeps the previous calm layout. Shipped with Cloud suite 204/204 and app suite 412/412 green.

1.8.0 — Cloud service, AI artwork scenes, audit rounds (capability catch-up, 2026-09-08)

This page had stalled at 1.4.3 while the product kept moving — an external audit called out the gap, and this cumulative entry closes it. Shipped since 1.4.x: BrandForge Cloud (browser workspace — Supabase accounts, 3 text stages, deterministic vector visuals, per-plan monthly quotas; Paddle checkout stays behind the operator’s release gate), AI artwork scenes on Cloud Pro/Agency via the operator-enabled provider (scene on the hero banner; size banners stay deterministic vector), Desktop AI Image Design through your own API key, and the site’s free Policy & Claim scanner. Two independent audits (rendered-browser + source; adversarial claim-by-claim re-review) drove fixes across security headers, quota logic, the updater, latency budgets and disclosure wording.
