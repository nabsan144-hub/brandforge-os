## Bugs found in THIS round (all fixed in this working tree)

1. **Homepage "LATEST RELEASE" said v1.8 while release 1.9.0 had shipped.**
   `sales/index.html` now describes v1.9 (bold creative engine, essential
   option). Credibility issue for every first-time visitor.
2. **Homepage quick-start terminal showed `uvicorn main:app --port 8000`, but
   no `main.py` exists** (`python app/server.py` is the real entry; Windows
   uses SETUP-WINDOWS.bat / START-HERE.bat). Copy fixed to
   `cd app && python server.py`. A customer pasting the old line would have
   hit a ModuleNotFound error within minutes of purchase.
3. **Release flag out of date:** `sales/changelog.html` and `CHANGELOG.md`
   marked 1.9.0 "(in development, not yet released)" while version_info,
   pyproject, the demo page and both engines were already 1.9.0. Flags
   updated to `(2026-09-11)`.
4. **Pricing FAQ was rendered twice** — a static card list ("Frequently
   asked") with an older, shallower answer set **and** the interactive
   `<details>` section ("Questions buyers ask") whose answers match the
   FAQPage JSON-LD. Kept exactly one visible source of truth (the interactive
   section + JSON-LD); removed ~6.5 KB of stale duplicate copy.
5. **Homepage $199 Owner CTA was the only Desktop button missing the
   `data-cta-*` attributes.** If Desktop checkout ever opens, that one button
   would have kept saying "waitlist" while every sibling upgraded to "Buy
   once". Now carries the same attribute contract; label flips
   automatically via the existing relabel hook.

Ambiguity call made: on (4) two visible FAQ presentations existed with
divergent answers. The `<details>` section was kept because its answers are
the ones mirrored by the FAQPage structured data — deleting the other is the
only way to guarantee a single honest answer per question.
