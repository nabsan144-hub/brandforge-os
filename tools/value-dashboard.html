    Measurement contract and limitations

    One record per generated pack, including unsuccessful exports. Use opaque customer and campaign references, never names, emails, prompts or API keys. Set usable to null until assessed. Use null for unknown durations and costs; zero means measured zero. Reviewed and exported are separate booleans. Manually collected durations must describe actual editing/first-usable-export timing, not estimated minutes saved.

    The customer denominator includes only customers represented in the imported records. It is not all signed-in active accounts. Unknown costs are reported; cost per usable pack is withheld until every selected pack has a cost. No model converts generation volume into assumed revenue, profit or customer satisfaction.
